# Career Architect: Custom GenAI Orchestration Agent

An advanced, multi-module custom GPT/Gemini Agent architected to act as a data-driven career consultant, resume optimization engine, and technical interview simulator. Built using first-principles system formatting, role-based behavioral rules, and external engineering playbooks.

## 🚀 Core Philosophy: "Context over Control"
Instead of relying on generic LLM outputs, this agent is hardwired to process unstructured career payloads (raw logs, job descriptions, and system configurations) through a customized, multi-layered instruction block. It strictly enforces background-check verification formatting while dynamically tailoring functional value-add sub-headers.

## 🛠️ Architecture & Core Modules

The agent operates across 9 distinct programmatic layers:
1. **Strategic Fit & Probability Audit:** Executes a multi-point vector comparison between incoming JDs and a tailored "Triple Threat" technical profile, outputting an explicit callback probability score.
2. **Compensation & Culture "Vibe-Check":** Cross-references live financial and sentiment registries (Levels.fyi, Blind, SEC EDGAR) to audit company stability and flag low-autonomy "ticket factories."
3. **External Knowledge Modules:** Programmatically ingests specialized remote sourcing repositories and technical deconstruction playbooks (e.g., the Knight's Dialer framework).
4. **Data Detective Sandbox:** Simulates enterprise-grade engineering failures (SQL schema drift, n8n rate-limit traps, API payload disconnects) for rapid interview preparation.
5. **The Post-Interview Debrief Protocol:** Parses raw user voice memos or text notes immediately post-interview to isolate silent objections and generate a consultative follow-up artifact.
6. **The "ECHO" Voice Engine:** A customized tone replication module trained on real professional correspondence and technical logs to eliminate standard AI cadence and enforce gritty, outcome-oriented pragmatism.

## 📈 Engineering Impact & Key Takeaways
* **Automation of Manual Debt:** Compressed the individual target-role resume optimization lifecycle from hours to minutes.
* **Deterministic Output Controls:** Eliminated model drift and hallucination during document generation by implementing hard boundaries regarding corporate titles and background check verification fields.
* **Vertical Integration:** Demonstrated a framework for treating prompt configurations as modular, version-controlled system architecture.
